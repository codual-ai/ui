# @codual/react-native-ui

Headless behaviors for React Native apps: screen states, lists (including chat-style reversed lists), forms,
purchases, selection, sheets and dismissal, search, permission prompts and chart interactions. The same behaviors,
with the same tested edge cases, as Codual UI's SwiftUI and Jetpack Compose packages. Your app keeps its own views.

```sh
npm install @codual/react-native-ui
```

Optional adapters, each with its library as an optional peer dependency:

- `@codual/react-native-ui/react-native-iap` for purchases with react-native-iap
- `@codual/react-native-ui/react-native-permissions` for permission prompts on iOS with react-native-permissions
- `@codual/react-native-ui/victory-native` for chart touch with Victory Native

Documentation, the specs and the skill for coding agents: [github.com/codual-ai/ui](https://github.com/codual-ai/ui).
